首页与起始页
把本页设为浏览器的「主页 / 启动时打开的网页」，打开浏览器就是你的收藏首页：光标自动落在搜索框，直接打字即可找收藏或搜索网页。
Chrome / Edge：设置 → 启动时 → 打开特定网页，再到「外观 → 显示主页按钮」填同一地址。Firefox：设置 → 主页 → 自定义网址。Safari：设置 → 通用 → 主页。手机：浏览器菜单「添加到主屏幕」或上方「安装为应用」。
这两项记在本浏览器的 Cookie 里，各设备可以各设各的。

接口字段
每个字段 = 一条 curl 请求 + JSON 取值路径 + 转换类型。刷新时按启用字段逐个取值；凭证以明文存于 config.json。
暂无接口字段，点击「添加字段」配置余额、到期时间等。
