# AICheckIn · Bookmark Hub

一个自托管的个人面板：**收藏库**（网址分组 + 站点图标）、**站点看板**
（把任意接口的余额 / 到期时间 / 用量抓回来显示）、以及 **自动签到**
（复用 `gyqd.py` 的签到逻辑，支持每日定时执行与运行历史）。

单文件 Flask 应用 + 单文件前端模板，数据全部落在一个 `config.json` 里，
没有数据库，容器只挂一个 `data/` 目录。

---

## 快速开始

```bash
git clone https://github.com/AceDylan/AICheckIn.git
cd AICheckIn

# 1. 设置管理密码（公网部署必须，见 SECURITY.md）
cp .env.example .env && chmod 600 .env
python3 -c "import secrets; print(secrets.token_urlsafe(24))"   # 把结果填进 .env

# 2. 起服务
mkdir -p data
docker compose up -d --build

# 3. 打开 http://127.0.0.1:5525
```

`.env` 里没有 `GYQD_ADMIN_PASSWORD` 时 compose 会直接报错退出——这是刻意的，
避免「以为设了密码、其实完全开放」。本地玩票不想设密码的话，在 `.env` 里填一个
值即可（未设置密码的语义是**全部开放**，不要用于公网）。

## 功能

- **收藏首页 = 浏览器起始页**：默认进入收藏首页，可直接设为浏览器主页（「系统设置 → 首页与起始页」有地址与各浏览器的设置步骤）。
  - 顶部是时钟问候 + 一个搜索框：桌面端打开即聚焦，**直接打字**就开始搜。先在**全部收藏**里找（不只是首页上那几个），像网址就直接打开，都不是就交给搜索引擎（Google / Bing / 百度 / DuckDuckGo：点搜索框左侧的按钮下拉选择，输入时按 `Tab` 可快速轮换）。输入的网址库里还没有时，下拉里会多一行「收藏它」。手机上虚拟键盘弹起时，下拉按可视视口收高度，最后一行「用 xx 搜索」不会被键盘盖住。库里一个网址都没有时（刚部署），首页的空状态直接给「新建第一个分组 / 添加第一个网址」和「导入 JSON / 备份」，而不是引去空的「自定义首页」。
  - **编辑首页**：点右上角的「编辑」进入整理状态——直接**拖动图标调整顺序**（鼠标按住就拖；手机上先按住约半秒，直接滑动仍然是滚动页面），点图标角上的「−」从首页移除，键盘用方向键挪动、`Delete` 移除、`Esc` 退出。首页没有单独的一份顺序：它沿用「看板在前、分组顺序在后」，所以拖动就是在原分组里调整这几个网址的相对位置（没上首页的网址原地不动，只能在同一个分组里拖，分组页同步变化）。说明条上的「选择网址…」打开「自定义首页」弹窗，从**站点看板**和所有分组勾选要展示的内容：顶部可按名称 / 网址 / 分组名筛选、只看已选，每个分组一键全选，「全选 / 清空」只作用于当前筛选结果；标题和「保存」固定在头尾，上百个网址也不用滚到底。任意卡片的「···」菜单也支持「展示到首页 / 从首页移除」。
  - **常用一行**：这台设备上点得最多的网址，会在首页最前面排成「常用」一行——正好一行，当前放得下几列就显示几个（电脑最多 10 个，手机 4 个），窗口变宽变窄跟着增减。首页图标、看板小组件、分组页卡片的点击（含中键新标签页打开）和搜索结果的打开都算数，没放上首页的网址也能进来；至少 3 个网址各点过 2 次才会出现，点击当下只记数、不重排（图标不会在手底下换位置），下次打开首页才更新。图标的「···」菜单里可以「不在常用里显示」；「外观」弹窗里可以整个关闭（同时清掉记录、不再记）或「清空记录」。记录只在本机 Cookie `bh_home_hits` 里：网址的 32 位短哈希 + 次数，最多 24 条、不含网址本身，14 天不点热度减半；点了什么不会上报服务端。编辑首页、卡片密度下这一行让路。
  - **分组折叠**：每个分组标题行最右有个折叠按钮（悬停 / 聚焦时显形，触屏常驻），不常用的分组可以留在首页但收成一行标题（计数还在，内容不渲染、也不去取图标）。折叠状态记在本机 Cookie `bh_home_fold` 里，各设备各折各的；极简密度没有标题行，折叠不生效。
  - **版面**：图标视图是一张统一的列网格（列数按主区实际宽度量出，最多 10 列）：所有分组共用同一组列线，左边线对齐、分组标题和第一个图标对齐，两三个网址的小分组照旧并排；宽屏上「图标 + 组件」作为一个整体居中在时钟和搜索框下面。密度 / 外观 / 组件 / 添加 / 编辑这几个偶尔才用的按钮收在右上角（主区不够宽和手机上收进时钟行右端的「⋯」，点一下展开），不再横在搜索框和图标之间；未解锁的访客看不到「添加 / 编辑」。
  - 三种密度：**极简**（只有大图标和名字，所有分组连成一张网格；看板站点平时和普通图标一样安静，取数失败 / 到期时才亮出指标）、**信息**（默认；保留分组，配了监控字段的看板站点显示为 2×1 **小组件**：名称、状态点、余额、到期倒计时）与**卡片**（显示描述、标签；看板站点显示全部监控字段并可就地刷新）。图标不带卡片底板，约 60px 的圆角大图标 + 名字；手机上是四列网格，两三个网址的小分组会并排放，不再各占一整行。
  - **外观**（首页右上角的「外观」或「系统设置 → 外观」）：壁纸与导航形态对**全部页面**生效——收藏首页、分组、站点看板、签到中心、系统设置是同一套样子，切页时不会在「壁纸起始页」和「工作台」之间来回跳。
    - 壁纸：**默认不开**（三张内置壁纸都是深色，一开整页就固定成深色场景）；在「外观」里手动选择后记在本机 Cookie。3 张内置壁纸（极光 / 暮色群山 / 晨雾山林），也可以上传自己的图片（需要管理权限；浏览器里先压缩到 2560px 以内再上传，存到 `data/wallpaper/`）。壁纸一律从本站加载——页面 CSP 是 `img-src 'self' data:`，没有为壁纸放宽，起始页也就不会把你的打开习惯泄露给图床。
    - 有壁纸时整个工作区（侧栏 + 全部页面）固定为「深色玻璃 + 白字」场景；弹窗、命令面板、提示条同样固定深色（实底），浅色主题下不会从深色场景里弹出一块纯白弹窗——深色 / 浅色主题只影响关掉壁纸之后的界面。遮罩分柔和 / 适中 / 加强三档；画面偏亮时会按「白字对比度 ≥ 4.5:1」自动加深，上传图片的亮度在压缩时顺手量好。
    - 半透明毛玻璃只用在搜索框、导航和页头这几块大面上；卡片、图标和小组件用半透明实底，手机不掉帧。电脑上侧栏离开窗口边缘、浮成一块圆角玻璃。浏览器不支持毛玻璃、系统开了「减少透明度」时换成实底；开了「提高对比度 / 强制颜色」时壁纸整个让路；省流量模式只显示主色渐变、不下载图片。
    - 关掉壁纸时是「倒 L」版面：侧栏落在页面底色上，内容区是一块带细边的圆角画布；页头是标题 + 说明 + 操作 + 一条细分隔线，不再是一整块卡片。配色走「纸与墨」：界面本身是黑白的（中性色带一点暖，深色是暖炭黑、浅色是米白纸），主按钮是墨色实心（深色主题里白底黑字），唯一的彩色是信号蓝——焦点、链接、开关打开、今天；颜色留给站点图标、分组色和壁纸。按 OKLCH 取值，深 / 浅两套的次要文字在各自底色上都 ≥ 4.5:1。网址在分组页是一块面板里的一行行，看板卡片的字段不再各自套一个框；手机底栏浮成一条圆角胶囊。系统设置在电脑上（未开壁纸）是一节一节往下排的「左标题、右内容」，弹窗底部的「保存 / 取消」贴住弹窗底边，内容再长也看得见。可按的小控件按下时缩到 97%，菜单从触发它的那一侧长出来（强 ease-out，160ms），开关按住时圆钮会拉长一点。分组页和站点看板的页头左边有一块带分组色的图标（像 Notion 的页面图标），每个分组一眼能认出来。
    - 电脑上侧栏默认收成一条 72px 的图标栏，所有页面一致；侧栏底部的按钮或「外观」弹窗可随时展开成完整侧栏，选择同样对所有页面生效。图标栏里每个入口都有即时的名字提示（悬停约 0.1 秒或键盘聚焦即出，`Esc` 收起），不用等浏览器原生提示那一秒多。手机始终是底部标签栏。
  - **站点图标清晰度**：抓取图标时高清优先（矢量、120–256px 位图、`apple-touch-icon`，站点没声明时还会探一次约定路径 `/apple-touch-icon.png`）；原图不到 64px 的小 favicon 不会被硬拉大，而是按原尺寸居中摆在底板上。**图标底板跟着图标自身的明暗走**：透明底的白色 / 浅色 logo 垫深色底板（否则在浅色底板上是一片纯白），透明底的黑色 / 深色 logo 垫浅色底板（否则在深色主题和壁纸上糊成一团），彩色图标和自带底色的图标不变；只换底板，不对图标做反色或滤镜，首页、分组、看板、签到、全局搜索里的头像都适用，强制颜色模式下底板保留自己的颜色。个别站点抓不到高清图标时，可在编辑网址时上传备用图片。
  - 看板里有站点取数失败 / 已过期 / 7 天内到期时，首页搜索框下方会出现提示，点一下直达看板并筛出这些站点。
  - **首页组件**：日历、待办、倒数日、便签、到期提醒、签到状态六种，默认放「日历 + 待办」。点右上角的「组件」（手机上是标签条末尾的那个小方块，「外观」弹窗里也有入口）打开「首页组件」弹窗：**开关 = 添加 / 移除**，**排序**可以拖把手、点 ↑ / ↓，或聚焦把手后按方向键；每张卡片标题行的「···」里也有「前移 / 后移 / 从首页移除」。改动立刻生效，没有「保存」这一步；「恢复默认」回到日历 + 待办。
    - **版面**：宽屏（图标栏 ≥ 1100px、完整侧栏 ≥ 1280px）组件排在图标右侧一列并吸顶，不占图标的位置，每张卡片可以单独收起，整列比窗口高时自己滚动；窄屏和手机上收成**一行标签**，每枚标签带一句要紧的话（「中秋节 5 天」「3 项」「2 个临期」），点哪个展开哪个、同一时间只展开一张，默认全收着——起始页的第一件事是点开网站，组件不把图标挤出首屏。
    - 哪些组件上首页、先后顺序、谁收着，记在本机 Cookie（`bh_home_deck` / `bh_home_deck_fold` / `bh_home_deck_open`）里，手机和电脑可以各摆各的；组件里的**内容**（待办、倒数日、便签）存在服务端，换设备也在。旧版 `bh_home_todo` 里「隐藏 / 收起待办」的选择升级后照旧生效，直到你第一次动组件设置。
    - **日历**：月历（周一起头）+ 农历，顶上是**下一个节日**和倒计时，后面再带两三个节日（其中总有一个是放假的），点一下跳到那一天。今天过节显示「今天」，正在放假显示「放假中 · 第几天 / 还有几天收假」。法定假期的格子标「休」、调休上班的周末标「班」，今天要调休上班时标题行会直接写出来。点任意一天看农历、节日和「还有几天 / 过去几天」；键盘用方向键按天 / 按周走，`Home` / `End` 到周一 / 周日，`PageUp` / `PageDown` 翻月，整张月历只占一个 Tab 停靠点。全部在浏览器里现算，**浏览器不请求任何外部服务**：公历节日、母亲节 / 父亲节、清明（节气公式）直接算；农历查页面内置的 1900–2100 年月历表（与香港天文台数据逐日一致，有测试锁定——特意不用浏览器自带的 Intl 农历，它会把 2027 年春节算成 2 月 7 日）。「哪几天放假、哪几天调休」每年由国务院办公厅公布、算不出来：页面内置了已知年份（`templates/index.html` 的 `HOLIDAY_PLANS`，目前有 2026 年），两边都没有的年份节日照常显示，只是不标「休 / 班」。
    - **同步放假安排**：新一年的通知一般在上一年 10–12 月发布。解锁后日历底部写着「放假安排：2026 年已收录 · 2027 年未收录」，点旁边的「**同步放假安排**」，由服务端去中国政府网（国务院政策文件库）找「国务院办公厅关于 YYYY 年部分节假日安排的通知」，查今年和明年：找到的逐条解析并自检（星期几、天数、七个节日齐全、调休只在周末……对不上就整份不采用），在卡片里预览——文号和发布日期（链接回原文）、每个假期的起止、调休上班日，以及和日历现在的相比是「新增 / 有更新 / 已是最新」；还没发布的年份写「还没公布」。点「**保存到日历**」才生效（存进 `data/holidays.json`，同一年以同步来的为准，访客看到的日历也跟着更新）；什么都没变就只显示「已是最新」。连不上或政府网的检索接口变了时如实报错、日历不动，并可以把通知链接（必须是 `www.gov.cn/zhengce/…`）粘贴进去改用链接检查。
    - **倒数日**：生日、纪念日、截止日期——「还有 N 天 / 今天 / N 天前」，近的排前面，7 天内变色。可以不重复、每年按**公历**重复，或每年按**农历**重复（农历生日；2 月 29 日、农历三十这种不是年年都有的日子，当年没有就落在月末），重复的会显示是第几个周年。新建时日期默认带上月历里点选的那一天。最多 50 个，存在服务端的 `data/deck.json`。
    - **便签**：一块随手记的地方（最多 2000 字，保留换行），停笔约一秒自动保存，失焦、切到后台时立刻保存；正在写的时候，别的设备同步过来的内容不会把手里这份冲掉。和倒数日存在同一个 `data/deck.json`。
    - **到期提醒**：站点看板里配了「时间」字段的站点（每个站点取最早到期的那个字段），按到期先后排，已过期 / 7 天内到期的变色，没放上首页的站点也在里面；点名字打开站点，「去站点看板」处理。
    - **签到状态**：今天启用的签到账户签了几个、定时签到开没开、还有几个等补签，点一下去签到中心。
    - 待办、倒数日、便签、签到状态**读写都需要管理权限**：未解锁时卡片里只有「去解锁」，开放的 `/api/configs` 不会下发这些内容；日历和到期提醒不含私人数据（到期提醒用的就是看板本来公开的字段），访客也能看。私密模式未解锁时整个组件区不出现。
  - **待办**（首页组件之一）：输入后回车添加，勾选完成（已完成的收进可折叠的一栏，可一键清除：按钮原地变成「确认清除 N 条？」，3 秒内再点才删，不弹系统对话框），悬停或聚焦时出现「修改 / 删除」，修改时 `Enter` 保存、`Esc` 取消、点到别处也保存。**排序**有三条路：按住拖动（鼠标可以拖整行，手机 / 触屏从行首的把手 `⠿` 拖，列表会跟着自动滚动）；点一下把手弹出「置顶 / 上移一位 / 下移一位 / 移到最后」；键盘聚焦到把手后按 `↑/↓`、`Home/End`（任意位置的 `Alt + ↑/↓` 仍然可用），结果会念给读屏。排序走 `POST /api/todos/<id>/move`（「挪到某一条的前 / 后」），另一台设备刚加过待办也不会因为列表不一致而失败。勾选、删除、排序都是先在本地生效、请求按顺序排队发出——连着勾几条不会丢，失败时自动向服务端对账。待办里写的 `http(s)://` 网址会变成**可点的链接**（新标签页打开，点链接不会顺带勾选；中文里网址后面不空格直接跟标点也能正确切开）：显示的是解析后的「主机名 + 路径」，完整地址在悬停提示里，修改时看到的仍是原文。数据存在服务端的 `data/todos.json`，换设备也在；**读写都需要管理权限**，未解锁时只显示「去解锁」，开放的 `/api/configs` 不会下发待办内容。
  - 打开方式（新标签页 / 当前页）、搜索引擎、首页密度、壁纸 / 遮罩 / 导航形态都记在本浏览器的 Cookie 里，各设备可以各设各的。
  - 首页搜索框是独立的搜索表单；管理密码框自成一个登录表单，并且只在「系统设置且尚未解锁」时才存在于页面中——否则手机浏览器的密码管理器会把搜索框当成「用户名」，一点就提示 / 填充已存密码。
- **网址图标**：编辑网址时可上传备用图片（PNG、JPEG、WebP、GIF、ICO，最大 2 MB，自动缩为 128 像素静态 PNG）。显示顺序为自动获取的图标 → 上传图片 → 文字头像（可选 emoji，否则首字母）；上传图标始终保留，自动图标再次不可用时继续回退。首页选择及图片随配置保存、备份和导入导出。
- **分组管理**：支持拖拽排序、置顶、标签；站点看板仍是独立子页面。
- **精简导航**：左侧仅保留收藏库、签到中心、系统设置；收藏分组随收藏库展开，分组多到放不下时只有分组这一段滚动（两端淡出提示），「签到中心 / 系统设置」始终留在原位。签到中心顶部是一组分段标签「概览 / 服务配置 / 运行记录」（当前页高亮、服务配置上带账户数），右边只放当前内页自己的操作（概览是「运行全部签到」，服务配置是「导出 / 导入 / 新增账户」，运行记录是「刷新记录」）；状态行里的「每日定时」点一下直达系统设置里的开关。启用的账户可以摆成「卡片」或「列表」（区块标题右侧切换，记在本机 Cookie `bh_ck_view`；没选过时超过 6 个账户自动用列表）：列表一行一个账户——状态、余额、最近一次结果或失败原因、签到 / 测试。原有 `#configs` / `#history` 链接继续兼容，新地址为 `#checkin/configs` / `#checkin/history`。
- **站点看板**：为每个站点配置若干「接口字段」，粘贴浏览器的
  `Copy as cURL`，指定 JSON 取值路径，即可把余额 / 到期时间 / 请求数抓回卡片。
  支持金额换算（除数 + 单位）、时间戳转本地时间（可指定时区）、原值直显三种类型。
  金额字段可设「低于多少提醒」（标「余额偏低」），时间字段可设「提前几天提醒」（默认 7 天）；
  超过两个刷新间隔（没开自动刷新按两天）没更新的值标「较旧」。签到账户可在「服务配置」里一键「加到看板」，
  余额字段按签到时查钱包的同一个接口自动配好，不用再抓 cURL。
- **自动签到**：配置多组平台账号，一键全量签到或单站签到；可开启每日定时执行，
  保留最近 50 条运行历史。当天失败的账号会自动补签几次（只重跑没签成的那些）。
  「运行全部签到」在后台执行（`POST /api/checkin/jobs`，页面轮询进度，卡片逐个出结果）：
  不同站点最多 `GYQD_CHECKIN_WORKERS`（默认 3）个同时签，同一站点的账户依次签，慢站点不再拖到反向代理超时。
  每个账户最近一次签到的状态、失败原因和时间会持久化，刷新页面后卡片仍显示「失败 + 原因」；
  每天留一个余额点（90 天），卡片上画走势线并估算日均用量与还能用几天。
  账户弹窗可先「测试连接」再保存。签到账户和看板站点的接口按下标定位，页面会带上稳定键（`?expect=`），
  别处删过 / 排过序后下标错位时服务端回 409，不会改到别的条目上。
- **自动刷新**：站点看板的接口字段可按 15 分钟 ~ 1 天的间隔后台自动取数，
  余额 / 到期时间不必手点也保持新鲜。
- **全局搜索**：⌘K / Ctrl+K 唤起命令面板，跨全部分组搜网址、看板站点与签到配置；
  输入 `#标签` 按标签筛选。也能搜**页面和命令**：输「签到」「运行记录」「设置」「深色」「壁纸」「添加网址」……回车直接执行
  （跳页面、运行全部签到、刷新看板、切主题、打开外观 / 首页组件 / 快捷键）；命令只在输入后出现，没有权限的不列出。
- **弹窗与键盘**：弹窗打开时 `Tab` 在弹窗内循环，关掉后焦点回到打开它的按钮（从「···」菜单打开的回到菜单按钮）。
  添加网址时「描述、标签与图标」默认收起（只填网址就能保存，标题自动取），编辑已填过这些的网址时自动展开。
- **死链检查**：分组页点「检查链接」逐条探测，打不开的加角标并可一键筛出；
  401/403 这类「活着但不给匿名访问」不算死链，内网服务可单独设为忽略检查。
- **配置恢复**：每次写入前留 `.bak`、每天首次改动另存一份（默认留 7 天）；
  误删分组或配置文件损坏时，可在「系统设置 → 配置恢复」里选一份回退。
  数据目录里若有 `config.json.pre-import.bak`（一次性数据迁移前手工 / 脚本留下的回溯点），也会列在这里，删掉该文件即消失。
  待办单独存在 `todos.json`、倒数日和便签存在 `deck.json`（各自带 `.bak`），勾选待办、写便签不会改写 `config.json`，也就不会把它的 `.bak` 冲掉。
- **PWA**：可安装为独立应用，应用外壳离线可用（接口数据一律不缓存）。
- **省流量、开得快**：起始页每开一个标签页就要一次应用外壳，所以——
  - 文本类响应（页面、样式、接口 JSON）按需 **gzip**，体积降到原来的三成左右（首页 HTML 约 390 KB → 117 KB）；前面有没有反代都一样，反代已经在压缩也不冲突。
  - 首页带内容哈希的 **ETag**：内容没变就是一个 304（几百字节），不再整份重传；样式表、站点图标（一天新鲜期过后）同样走 304，内置壁纸有一天的新鲜期。
  - **数据请求提前出发**：`/api/configs` 在 `<head>` 里就发出去，和页面其余部分的下载、解析并行，主脚本跑起来时直接接手结果（限速网络下实测「数据到位」早 40–80 ms）。
  - **回到页面时自动对一下数据**：标签页挂了一阵（≥ 1 分钟）再切回来，会悄悄重取一次——手机上勾掉的待办、另一台电脑上加的网址、后台刷新出来的余额不用手动刷新就能看到。
    只在收藏库（含首页）做；弹窗开着、正在编辑首页 / 改待办 / 写便签、输入框里有字时不打扰；失败不提示。
  - **第一次加载没成功会自己再试**：新标签页开得比网络恢复还快（电脑刚唤醒、手机刚出电梯）时，隔 2 / 5 / 15 秒静默重试，网络一恢复或切回这一页立刻补上，不必手动刷新。
- **快速收藏**：装成应用后出现在手机系统「分享」菜单里；桌面可把书签小工具拖到
  书签栏，在任意网页点一下即带着当前网址与标题打开收藏弹窗（只预填，不自动保存）。
  也可以直接把链接（别的标签页里的链接、地址栏左侧的站点图标、书签栏上的书签）**拖进这一页**：
  出现「松手收藏这个网址 · 添加到「当前分组」」，松手打开同一个收藏弹窗，网址和链接文字都预填好；
  页面自己的拖动（图标、网址行、待办）不会触发，未解锁时也不会。没带标题时会自动读取网页标题。
- **导入导出**：整份配置一键导出 / 导入（含凭据，**按机密文件处理**）。导出文件带 `todos` 键（首页待办）和 `deck` 键（倒数日、便签）；导入时有对应的键才覆盖，旧版导出的文件照常可用。

### 真实浏览器回归

拖拽、触摸、焦点、版面这些只有真浏览器里才验得出来的行为，放在 `tests/browser/`（PC 与手机视口都跑）：

```bash
pip install playwright && playwright install chromium   # 只是开发期依赖；已有 Chromium 的话用 BH_CHROME=/path/to/chrome 指过去

python tests/browser/run_all.py                          # 六套全跑，约 3 分钟，末尾一张汇总
python tests/browser/verify.py todo_desktop todo_mobile  # 只跑某一套里点名的几段
```

| 脚本 | 覆盖 |
| --- | --- |
| `verify.py` | 待办排序（鼠标 / 触摸 / 菜单 / 键盘，按 id 核对拖的是哪一条）、首页版面与列网格、编辑首页、自定义首页弹窗、常用一行、分组折叠、权限与 XSS、减少动态效果 / 强制颜色、性能 |
| `verify_deck.py` | 首页组件：右侧一列 / 标签条、添加移除排序、日历、倒数日、便签、访客视角 |
| `verify_polish.py` | 空库引导、小字对比度、键盘下的搜索下拉、壁纸场景浮层、清除已完成 |
| `verify_railtip.py` | 图标栏的即时名字提示 |
| `verify_transport.py` | gzip、ETag / 304、壁纸新鲜期、回到页面静默对数据、首次加载失败自动重试 |
| `verify_embed.py` | 被 HaloWebUI 嵌入：白名单内 / 外的宿主页、票据换管理员会话（一次性、过期、伪造、probe）、被嵌入时外链一律新标签页、Service Worker 激活后仍嵌得进来 |

每次运行都用当前工作树在 `127.0.0.1` 的空闲端口上现起一个实例：数据是 `tests/browser/seed/` 里的**合成数据**（拷到临时目录，跑完即删），
管理密码每次现生成、只存在于进程环境里；站点图标在浏览器侧用本地现画的 PNG 顶替，任何离开本机的请求都会被掐掉并记为失败——
不碰真实部署，也不向外发一个字节。`BH_VERIFY_SHOTS=<目录>` 可以把过程截图留下来。

首页默认版面下待办卡片排在日历下面、1440×900 时落在首屏以外，而页面开着平滑滚动：脚本里凡是要按坐标操作的地方，
都先用 `settle()` 瞬时滚进视野并等位置停稳再量坐标，否则鼠标会落在别的行上。
这几套不进 `unittest discover`（没装 Chromium 的机器照常能跑单测），但 `tests/test_browser_suite.py` 会静态核对
脚本里点名的每个 `#id` / `data-*` 在页面里都还在——页面删了元素而脚本没跟上，当次提交的单测就会红。

### 内置壁纸与素材授权

`static/wallpapers/` 里的图片全部由 `tools/make_wallpapers.py` 程序化绘制（渐变、光斑、山脊线、噪点），
不含任何第三方照片或图库素材，随仓库以同一许可分发。想换画面就改脚本重新生成：

```bash
pip install Pillow            # 只是开发期依赖，运行时镜像不需要
python3 tools/make_wallpapers.py
```

脚本会同时写出 `manifest.json`（每张的主色与 p90 亮度）；页面里的 `WALLPAPERS` 常量要与它保持一致
（有测试核对），并把 `static/sw.js` 的 `CACHE_VERSION` +1——内置壁纸在 Service Worker 里是 cache-first。
上传的自定义壁纸走 `GET/PUT/DELETE /api/wallpaper`，不进 `config.json`、不随配置导出，
备份 `data/` 目录时会一并带上；图片的使用授权由上传者自己负责。

测试用 `tests/_support.py` 的 `StoreIsolationMixin` 给每个用例分配独立数据目录，
因此整套一起跑与单跑结果一致。新增会读写 `config.json` 的测试类请继承它。

## 「AI 聊天」标签页：把自己的 HaloWebUI 嵌进来（可选）

左侧标签栏多一个「AI 聊天」，点进去就是 HaloWebUI（本站是外层页面，HaloWebUI 在 iframe 里）。
一个地方管书签、随时点进去聊天；入口和地址都只给已登录（解锁）的人。配置写在本机的 `.env` 里，
**不要写进任何会入库的文件**：

```bash
# 1. HaloWebUI 的完整源（协议 + 主机 + 端口，不带路径、不支持通配符）。留空 = 没有这个标签页。
HUB_CHAT_URL=https://host.acedylan.us:3001

# 2. 免登录（可选）：本站管理员已解锁 = HaloWebUI 已登录。现场生成一个随机密钥，
#    HaloWebUI 那边的同名环境变量填同一个值：
#        python3 -c "import secrets; print(secrets.token_hex(32))"
HUB_TRUSTED_EMBED_ADMIN_SECRET=<现场生成的随机值>
```

HaloWebUI 那边要做的：`HUB_URL` 写本站的地址（它据此在自己的响应头里放行本站嵌入，并只认本站签的票据），
`HUB_TRUSTED_EMBED_ADMIN_SECRET` 填同一个值。改完两边各自 `docker compose up -d` 重建容器生效。验证：

```bash
# frame-src 里有 HaloWebUI 的源；本站自己仍然谁都不能嵌（frame-ancestors 'none' + DENY）
curl -sI https://<本站地址>/ | grep -i -E 'content-security-policy|x-frame-options'
# 未解锁：收藏、看板、AI 聊天一概不给（空壳），签票接口 403
curl -s https://<本站地址>/api/configs | python3 -c "import sys,json; d=json.load(sys.stdin); print(d['locked'], d['bookmarks'], d['chat'])"
curl -s -o /dev/null -w '%{http_code}\n' -X POST https://<本站地址>/api/chat/ticket
# HaloWebUI 那边：允许本站嵌入
curl -sI https://<HaloWebUI 地址>/ | grep -i content-security-policy
```

工作方式：已解锁的管理员打开标签页时，页面向 `POST /api/chat/ticket` 要一张 60 秒内有效、只能用一次的票据，
iframe 指向 `<HUB_CHAT_URL>/auth#hub_ticket=…`（放在 `#` 后面：不进任何服务器日志，也不进 Referer）。
HaloWebUI 验签通过后签发它自己的（较短的）会话。签不了票时（没配密钥、管理密码不合格……）标签页照样打开，
只是要在框里自己登录，页面顶部会说明原因。票据格式、密钥保管与「哪些情况绝不签票」见 [SECURITY.md](SECURITY.md)。

收藏库现在**默认登录后才出现**（设了管理密码即私密模式；确实要把首页当公开导航页给路人看的，显式设 `HUB_PUBLIC_LIBRARY=1`）。
升级后第一次在 HaloWebUI 里打开若仍被浏览器拒绝，单独打开本站刷新一次即可。

### 发送到 AI 聊天

配好上面两项之后，站里四个地方可以把一段话直接送进聊天，**都会先弹一个可编辑的框**——
搜索框里那半句话、一条待办、一整篇便签，原样丢给模型往往不是想问的问题：

| 在哪 | 按钮 | 带过去的是 |
|---|---|---|
| 首页搜索框 | 下拉里的「用 AI 回答「…」」 | 你输入的那几个字 |
| 收藏卡片的「···」 | 问 AI | 名称、网址、备注、标签 + 一句提问 |
| 待办每一条 | 让 AI 拆解 | 这条待办 + 「拆成可执行的几步」 |
| 便签组件的标题栏 | 发给 AI | 便签全文 |

确认后切到「AI 聊天」标签页，HaloWebUI 落地就自动把问题发出去（地址形如
`<HUB_CHAT_URL>/auth?redirect=%2F%3Fq%3D<问题>%26models%3D<模型>#hub_ticket=<票据>`）。
地址有两条硬上限：整条 6000 字符，以及 `redirect` 解码后那一段 2048 字符（对面的
`safeRedirectPath()` 就卡在这里，**超了是整条丢掉、跳回首页**，不是截断）。超了后端自己截断
并在页面上说一声——一个汉字编码两次要 15 个字符，一篇长便签足以撑爆一条 HTTP 请求行。
Ctrl / ⌘ + Enter 直接发。

**用哪个模型**：从这里问出去的是一句话的问题，要的是马上回一段话，所以地址里显式指定了模型
（`HUB_CHAT_MODEL`，默认 `gpt-chat`）——否则会落到 HaloWebUI 的默认模型上，而那可能是一个
跑长任务的 agent。**只有带着问题跳过去的地址才加这个参数**：光打开「AI 聊天」标签页、在框里
新建对话、以及 HaloWebUI 自己的任何入口，用的都还是对面自己的默认模型，这边一个字都不改它。

```bash
# .env
HUB_CHAT_MODEL=gpt-chat     # 留空 = 不指定，用 HaloWebUI 的默认模型
# 对面同名模型不止一个时写完整的连接限定 id：modelref::openai::<某连接>::gpt-chat
```

## 笔记（WebObsidian）：速记进收件箱 / 搜笔记 / 待办镜像（可选）

接上自己的 [WebObsidian](https://github.com/AceDylan/webobsidian) 之后：

- 上面那个编辑框多一个「**存入笔记**」——追加到 `<收件箱>/<今天>.md`，带时间和来源；
- 首页搜索下拉多一行「**在笔记里搜索「…」**」，选中才真的去搜（**不是边打边搜**：跨机一次约半秒），
  结果点开就是 WebObsidian 的 `/note/<路径>` 深链；
- 待办组件标题栏多一个「**同步到笔记**」——把整份待办镜像成 `<收件箱>/待办.md`。
  **单向**：本站是真相源，每次整篇覆盖，在笔记里改这一篇下次同步就没了。

```bash
# .env
HUB_VAULT_URL=https://host.acedylan.us:3003   # 完整的源。留空 = 没有这些功能，接口一律 404
HUB_VAULT_API_KEY=wok_...                     # 对面「设置 → API Keys」生成，只给 write + search
HUB_VAULT_INBOX=收件箱                         # 本站只往这个文件夹底下写
HUB_VAULT_TIMEOUT=5                           # 出站超时（1..15 秒）
HUB_VAULT_TODO_MIRROR=0                       # 1 = 待办每次变动都在后台重写镜像
```

WebObsidian 那边要做的三件事：

1. **建 key**：设置 → API Keys，只勾 `write` 和 `search`（不需要 `read`）。原始 key 只显示一次。
2. **打开 git 自动提交**（设置 → Git：`enabled` + `autoCommitOnSave`）。
   **先做这一步再把 key 填进来**——否则误写进 Vault 的东西没有版本可回滚。
3. **反代放行 Agent API**：网页版若挂着 Basic Auth，`/api/v1/` 要单独开一个 `location`：

   ```nginx
   location /api/v1/ {
       auth_basic off;               # Agent API 用自己的 X-API-Key 认证
       proxy_pass http://127.0.0.1:18787;
       proxy_http_version 1.1;
       proxy_set_header Host $http_host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto https;
       # 千万别 include 受信代理头的片段：那个头本身就等于「不用 key 也算已登录」。
       # allow <Hub 的公网 IP>; deny all;   # 建议再加一层来源白名单
   }
   ```

   `nginx -t && systemctl reload nginx`，然后验证：

   ```bash
   curl -s -o /dev/null -w '%{http_code}
' -H "X-API-Key: $KEY" https://<笔记地址>/api/v1/health   # 200
   curl -s -o /dev/null -w '%{http_code}
' https://<笔记地址>/api/v1/health                        # 401
   ```

本站只有三个笔记接口，都要管理权限、都在没配置时 404：`POST /api/vault/capture`、
`GET /api/vault/search`、`POST /api/vault/todos/sync`。**写入路径永远由后端自己拼**，
请求体里没有「路径」这个参数，最后还要过一道「只许收件箱前缀」的闸。理由与威胁模型见
[SECURITY.md](SECURITY.md)。

> 想让 HaloWebUI 里的 AI **自己**去查笔记，用 HaloWebUI 仓库里的
> `integrations/webobsidian-tool/`（工作空间 → 工具，只读，另配一把 `read` + `search` 的 key）。

Service Worker 的缓存版本随这两次改动升到 v18。

### 「笔记」标签页：把 WebObsidian 整个嵌进来（可选）

左侧标签栏再多一个「笔记」，点进去就是自己的 WebObsidian；**本站解锁 = 笔记已登录**，
锁定本站笔记也跟着退出。入口只给已解锁的人。本站这边只要一个变量（再加上上面的 `HUB_VAULT_URL`）：

```bash
# 与 WebObsidian 共享的密钥：现场生成，WebObsidian 的 WEBOBSIDIAN_HUB_EMBED_SECRET 填同一个值。
# 别和 HUB_TRUSTED_EMBED_ADMIN_SECRET 共用。留空 = 没有这个标签页。
#     python3 -c "import secrets; print(secrets.token_hex(32))"
HUB_VAULT_EMBED_SECRET=<现场生成的随机值>
```

WebObsidian 那边：`.env` 写 `WEBOBSIDIAN_HUB_URL=<本站地址>` 和同一个 `WEBOBSIDIAN_HUB_EMBED_SECRET`，
拉新镜像重建容器；它前面的 nginx 要让「由本站登录的会话」也能过 Basic Auth，并给登录桥单开两个 `location`——
完整步骤、nginx 配置和验证命令在 WebObsidian 仓库的 `docs/HUB_EMBED.md`。

工作方式：框先打开本站自己的 `/vault/open`，后端在这一页里签一张 60 秒、只能用一次的票据，放在**隐藏表单字段**里
`POST` 给 WebObsidian 的 `/auth/hub/sso`（票据不经过页面脚本，也不进任何地址）；WebObsidian 验过来源、签名、
有效期和 nonce 后给它自己的 12 小时会话。锁定本站时页面顺带请它结束这个会话。细节见 [SECURITY.md](SECURITY.md)。
Service Worker 的缓存版本随之升到 v20。
